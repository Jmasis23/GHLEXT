How it works

User switches tabs → Clear any existing collapse timer → Start new timer (N seconds from settings) → Timer fires → collapse all other groups
  • Instant (0s) — same behaviour as before, groups collapse immediately on tab switch
  • 5s / 10s / 30s / 60s / 2m / 5m — wait N seconds before collapsing inactive groups
  • If you switch tabs again before the timer fires, it resets — only the group you settle on stays expanded
  • If the active tab is removed (closed), the timer is cancelled to avoid collapsing on a dead tab
